# Google順位チェッカー

指定したWebページが、検索ワードごとにGoogle検索の何位に表示されるかを記録するStreamlitアプリです。

## いちばん簡単な起動方法（Windows 10/11）

1. ZIPファイルを右クリックし、「すべて展開」を選びます。
2. 展開したフォルダ内の `start_windows.bat` をダブルクリックします。
3. 初回のみ必要なライブラリが自動でインストールされます。
4. ブラウザが開き、アプリが表示されます。

Pythonが未導入の場合は、先に https://www.python.org/downloads/ からPython 3.11以降をインストールしてください。その際「Add Python to PATH」にチェックを入れます。

## 本番順位の計測

本番計測はSerper API（Google検索結果API）を利用します。

1. https://serper.dev/ でAPIキーを取得します。
2. 画面左の「Serper APIキー」に入力します。
3. 「デモモード」をオフにします。
4. 対象URLと検索ワードを入力し、「分析開始」を押します。

APIキーなしでもデモモードで画面と履歴機能を確認できます。ただし、デモ順位は実際の検索結果ではありません。

## データについて

- 順位履歴は同じフォルダの `rank_history.db` に保存されます。
- 入力URLが同じ場合、過去365日分をグラフ表示します。
- 検索APIで上位100件に見つからない場合は「100位圏外」と表示します。
- ページ単位とドメイン全体の照合を選択できます。

## ターミナルから起動する場合

```bash
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

終了するときは、起動中の黒い画面で `Ctrl + C` を押します。

## 定期計測について

このアプリは「分析開始」を押すたびに履歴を蓄積します。完全な無人定期実行には、Windowsタスクスケジューラやクラウド環境から別途スケジュール設定が必要です。
